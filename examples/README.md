# Examples

This directory contains **synthetic, non-personal example data** for Career Evidence Toolkit.

## Current example

`profile.example.yaml` demonstrates the shape of an onboarding profile, including:

- candidate identity placeholders;
- optional public professional profiles;
- private storage configuration;
- evidence-source locations;
- target-role and template preferences; and
- explicit permission flags for reads and writes.

The paths, names, addresses, and profile URLs are placeholders. Do not replace them with a real person's career data in the public repository.

## Planned examples

The roadmap includes a broader fictional candidate evidence pack and behavioral scenarios covering initialization, master-resume updates, certificate conflicts, role-title targeting, and vacancy targeting.

When those fixtures are added, they should be deterministic enough to support repeatable validation while remaining entirely synthetic.

## Privacy rule

Examples must never contain real resumes, certificates, profile photographs, contact details, private URLs, account identifiers, application history, or other personal career records.
