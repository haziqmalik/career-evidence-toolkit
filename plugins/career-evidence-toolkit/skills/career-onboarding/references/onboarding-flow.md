# Onboarding flow

Ask in stages and reuse answers already supplied.

## 1. Identity

Collect full name, preferred professional name, broad location, professional email, optional phone number, and optional profile image. Explain where each field will appear.

## 2. Profiles

Collect optional LinkedIn, GitHub, portfolio, freelance-marketplace, publication, and personal-site URLs. Offer these access modes separately:

- accessible public information;
- authorized authenticated browsing;
- uploaded profile export;
- skip.

Do not describe access as unrestricted scraping. If a site blocks automated access, use an export or user-supplied source instead of bypassing the restriction.

## 3. Storage

Require one durable private destination: local folder, Google Drive, ChatGPT Library, Dropbox, or another available provider. Confirm the exact root before creating anything.

## 4. Existing evidence

Ask for previous resumes, master resumes, portfolios, employment records, project summaries, certificate files, public credential URLs, education evidence, and professional biographies. Preserve originals and record provenance.

## 5. Career direction

Collect target titles, seniority, industries, locations, remote preferences, employment types, strongest positioning, and facts the user does not want made public.

## 6. Permissions

Record permissions independently for public-profile review, authenticated-profile review, storage reads, storage writes, certificate renames, master-resume writes, and template activation. Connection alone is not authorization.

## 7. Templates

Offer default, restrained customization, or custom DOCX. Template approval is separate from approving generated resume content.
