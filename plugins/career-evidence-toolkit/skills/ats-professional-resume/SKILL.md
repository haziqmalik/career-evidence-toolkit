# ATS Professional Resume

Clone `assets/reference.docx`; never overwrite it.

## Workflow

1. Read `artifact-template.json` and resolve its paths relative to this skill.
2. Use an available document capability to clone and populate the reference. If none is available, explain the missing capability instead of recreating the design.
3. Use only approved, verified candidate content. Remove unused optional fields and unresolved placeholders.
4. Treat the resume as a continuous document. Choose one or two pages from useful evidence, not a fixed canvas.
5. Render and inspect every page before finalizing.

## ATS contract

- Preserve real text, conventional headings, bullets, single-column reading order, and printable bounds.
- Do not place important content in headers, footers, floating text boxes, charts, graphics, or multi-column containers.
- Keep a heading with enough following content to establish its section. Roles and projects may split between bullets when necessary.
- Do not add filler, force a page break, or shrink typography merely to hit a page count.
- Correct large avoidable page-one whitespace, nearly empty second pages, orphan headings, awkward title splits, clipping, and inconsistent spacing.

User instructions control content. The retained reference controls unrequested visual decisions.
