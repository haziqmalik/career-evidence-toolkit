# Evidence policy

Use this default authority order unless the user configures a justified alternative:

1. Direct current user correction.
2. Primary evidence such as a certificate, contract, repository, production record, or authored document.
3. Current approved master record.
4. Current public professional profile.
5. Specific recent conversation or work context.
6. Older contextual memory.

The job description and employer marketing are never evidence about the candidate.

Record source, confidence, attribution, maturity, and date precision. Never invent dates, metrics, titles, team sizes, clients, revenue, deployment status, credential IDs, or sole ownership.

Claim strength must not increase during rewriting:

- contributed does not become led;
- supported does not become owned;
- planned does not become implemented;
- staging does not become production;
- architected does not imply solely built.

When evidence is credible but imprecise, use conservative wording or request confirmation.
