# Support

Career Evidence Toolkit is a community-supported open-source project.

## Getting help

Before opening an issue:

1. Read the installation and onboarding instructions in [README.md](README.md).
2. Confirm that you installed the intended release.
3. Start a new agent conversation after installing or upgrading the plugin.
4. Run the repository validator if you are developing locally:

   ```bash
   python3 plugins/career-evidence-toolkit/scripts/validate_repo.py .
   ```

If the problem remains, open a GitHub issue:

https://github.com/haziqmalik/career-evidence-toolkit/issues

Include:

- the toolkit version;
- the agent and operating system used;
- the skill or workflow involved;
- minimal reproduction steps;
- expected and actual behavior;
- sanitized validation output, when relevant.

## Security and privacy

Do not include resumes, certificates, contact details, profile images, access tokens, private profile content, employer-confidential information, or other sensitive data in a public issue.

Report suspected security vulnerabilities using the process in [SECURITY.md](SECURITY.md), rather than a public issue.

## Scope

Support covers installation, plugin packaging, bundled skills, blank templates, validation scripts, and reproducible defects. It does not include:

- writing or verifying a user's career history;
- accessing private accounts;
- recovering files or credentials;
- guaranteeing compatibility with every third-party service;
- guaranteeing interviews, employment, or application outcomes.

There is no guaranteed response time or service-level agreement.
