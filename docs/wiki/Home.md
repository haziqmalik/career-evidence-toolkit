# Career Evidence Toolkit Wiki

Career Evidence Toolkit is an open-source set of agent skills for maintaining verified career evidence and turning it into truthful, role-specific resumes.

The toolkit is designed around one principle: **career documents should be generated from evidence, not invented from prompts.** Your personal career data stays outside the public plugin repository in a private workspace you control.

## Typical workflow

1. Install Career Evidence Toolkit.
2. Run `career-onboarding` and choose a durable private storage location.
3. Import an existing CV, professional profiles, project evidence, and certificate files.
4. Build or update the master resume with `master-resume-maintainer`.
5. Reconcile credentials with `certificate-registry-sync`.
6. Generate role-specific resumes with `targeted-resume-generator`.
7. Render the result with either the ATS or Executive template skill.
