# Security and privacy

## Supported versions

Security and privacy fixes are applied to the latest released version.

## Reporting

Report a vulnerability privately through GitHub's private vulnerability reporting feature when available. Do not open a public issue containing personal data, credentials, tokens, private resume content, or unpublished employment information.

## Data handling

This repository must contain no user career workspace. Users should store personal data in a private local folder or an authorized connected storage provider.

The toolkit must never request or store passwords, one-time codes, API keys, OAuth tokens, private keys, or payment information. Professional certificates may be called credentials, but authentication credentials are out of scope.

External access and mutations require the user's authorization. Never make a profile public, upload a document, rename evidence, edit a master resume, or submit a job application merely because a source is connected.
