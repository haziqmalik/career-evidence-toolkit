# Changelog

All notable changes to Career Evidence Toolkit are documented here.

The project follows semantic versioning where practical. Published releases remain the authoritative version markers.

## [Unreleased]

### Added

- GitHub Pages landing site.
- Version-controlled GitHub Wiki source under `docs/wiki/`.
- Automated Wiki synchronization from `main`.
- README project-health badges, documentation links, workflow overview, and contribution entry points.
- Community issue templates and code of conduct.

### Changed

- Expanded project documentation around evidence handling, privacy, installation, and repository structure.

## [0.1.0] - 2026-09-15

Initial public release.

### Added

- `career-onboarding` skill for private workspace setup and evidence discovery.
- `master-resume-maintainer` skill for master resume initialization and maintenance.
- `certificate-registry-sync` skill for certificate auditing and reconciliation.
- `targeted-resume-generator` skill for role-title and vacancy-specific resumes.
- ATS Professional Resume template skill.
- Executive / Senior Technical Resume template skill.
- DOCX template sanitization workflow.
- Repository validation workflow.
- Privacy, security, terms, support, contribution, and roadmap documentation.
